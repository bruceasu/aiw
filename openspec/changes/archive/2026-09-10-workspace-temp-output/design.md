## Context

`cz` 目前通过空目录参数让 Go 使用操作系统临时目录；两个内置 Skill 也要求将临时输出写入操作系统临时目录。仓库已忽略 `.ai/`，可作为每个工作区的临时输出根目录。

## Goals / Non-Goals

**Goals:**

- 将可丢弃、面向用户或工具流程的临时输出置于 `<工作区>/.ai/tmp`。
- 在目录不存在时创建它，并在既有流程结束时删除单次临时文件或目录。
- 让 Skill 的文字约定与工具行为一致。

**Non-Goals:**

- 不迁移 AIW Session、Workflow Core 或 OpenSpec 的持久化工件。
- 不改变原子写入的同目录临时文件；该位置是原子 `rename` 语义的一部分。
- 不提供跨工作区共享临时目录，也不改变公开 CLI 参数。

## Decisions

- 使用项目根目录下的 `.ai/tmp`，而非 OS 临时目录；`cz` 已有 `detectProjectRoot`，可复用其 Git 根目录/当前目录回退逻辑。这样临时输出属于当前工作区且由现有 `.gitignore` 排除。
- 在 `cz` 中引入一个小型目录解析辅助函数，统一创建 `.ai/tmp` 后再调用 `os.CreateTemp` 或 `os.MkdirTemp`。两种临时输出保留独立随机名称和 `defer` 清理。
- Skill 文档明确写入 `.ai/tmp`，并要求使用唯一文件名及在消费后清理。Session artifact store 优先级不变。
- 原子写入保持在目标文件所在目录，因为跨目录临时文件无法保证原子替换。

## Risks / Trade-offs

- [工作区只读或不可创建 `.ai/tmp`] → 将创建错误直接返回，不回退到 OS 临时目录，以保持位置约定可预测。
- [旧临时输出已留在 OS 临时目录] → 不迁移历史文件；新调用立即采用新目录。
- [Skill 产生的浏览器可视报告需要保留给用户查看] → 报告留在 `.ai/tmp`，使用唯一名称，用户可自行删除整个目录。
