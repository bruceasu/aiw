# codebase-design：模块与接口设计语言

## 用途与适用场景

讨论模块接口、职责边界和可测试性时使用。核心是用小而稳定的接口封装足够完整的
行为，减少调用方负担和跨模块修改，而不是为了增加抽象层而设计。

## 输入与输出

- 输入：模块职责、调用方式、变化压力和设计问题。
- 输出：接口／边界建议、取舍、可替换依赖与测试面的分析。

## 调用示例

```text
$codebase-design Review the boundary and interface of this module.
```

## 边界与资料

产出设计指导，不自动实现、提交或运行验证。使用子 Agent 时遵守入口规定的最多
两个有界静态分析及仓库预算；不是每次设计都强制并行。
概念定义与可选方法见 [SKILL.md](SKILL.md)。
