# ai-code-tools v1.2.0

Two global commands:

```text
generate-ai-index
ai-code-index
```

## What's new in v1.2.0

- `generate-ai-index` now writes symbol locations:
  - `line_start`
  - `line_end`
  - `id`
- API routes include:
  - `line`
  - `id`
- `PROJECT_MAP.md` and `API_INDEX.md` include location columns.
- `ai-code-index context` shows exact locations such as:
  - `src/main/java/.../UserService.java:127-156`
  - `src/main/java/.../UserController.java:88`

## Install

```bash
unzip ai-code-tools-v1.2.0.zip
cd ai-code-tools-v1.2.0
./install.sh
```

Default install target:

```text
~/.ai-tools
```

Add to PATH:

```bash
export PATH="$HOME/.ai-tools:$PATH"
```

Check versions:

```bash
generate-ai-index --version
ai-code-index --version
```

## Generate repo-local index

```bash
cd ~/work/order-service
generate-ai-index
```

or:

```bash
generate-ai-index --root ~/work/order-service
```

Outputs:

```text
.ai/PROJECT_MAP.md
.ai/API_INDEX.md
.ai/symbols.jsonl
.ai/apis.jsonl
.ai/files.jsonl
.ai/metadata.json
```

## Register repos and update global index

```bash
ai-code-index repo add ~/work/order-service
ai-code-index repo add ~/work/user-service

ai-code-index update --run-generator
```

## Search

```bash
ai-code-index search "create order api" --top 10
```

## Generate LLM context

```bash
ai-code-index context "订单创建接口失败" --top 8 --current-repo
```

Example output includes:

```text
- Location: `src/main/java/com/demo/order/OrderController.java:88`
- Location: `src/main/java/com/demo/order/OrderService.java:127-156`
```

## Suggested AI CLI prompt

```text
Please read the candidate context generated by ai-code-index first.
Use the listed repositories and file locations as the initial investigation scope.
Do not start by globally searching the entire workspace unless the candidate context is insufficient.
```

## Compatibility

`ai-code-index update --run-generator` prefers the global `generate-ai-index` command from PATH.

Fallback:

```text
repo/scripts/generate-ai-index.py
```
