# diagnosing-bugs：基于证据诊断故障

## 用途与适用场景

适合难以定位的错误、间歇故障或性能回归。尝试建立可观察的反馈方式，最小化问题，
提出可检验假设，并以实际证据缩小原因范围。

## 输入与输出

- 输入：症状、复现步骤、版本、日志／已有捕获，以及可访问范围。
- 输出：复现与最小化证据、原因／假设、限制和下一步；没有证据时不假装已定位。

## 调用示例

```text
$diagnosing-bugs Diagnose this failure from the supplied logs.
```

## 边界与资料

诊断与实施分开。运行时复现、测试、临时插桩和环境操作需要各自授权；未授权时
明确记为未运行，不能把静态推断写成复现成功。入口后续阶段依赖真实反馈证据，
无法获得时应说明阻塞，不无限尝试或猜测。见 [SKILL.md](SKILL.md)。
