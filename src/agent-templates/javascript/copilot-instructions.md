# JavaScript Project Guidance

Read `AGENTS.md` first, then `javascript/AGENTS.md`.

- Inspect `package.json`, the active lockfile, runtime configuration, and nearby tests.
- Preserve ESM or CommonJS, package-manager conventions, and supported runtimes.
- Keep validation at external data boundaries and handle asynchronous errors explicitly.
