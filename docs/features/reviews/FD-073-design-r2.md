来源事件：`FD-073-000002-design-requested`。FD 标头仍为 Revision 2，实际依据为本报告生成时包含以下决定的最新正文；r1 保留为历史。

- D1 已解决：`publication_mode=independent` 持久表达明确独立的 FD，允许其目标不同于父 Issue；默认和无标识旧冲突仍阻断。映射 `source_kind/source_id` 表示所有者，与受管投影身份分离；普通关联 FD 首次发布建立父 Issue 根摘要和该 FD 独立块。
- D2 已解决：所有远程写前原子登记映射旁 pending 凭据，登记失败不应发送写入；未完成凭据阻断新写入。响应目标先补入凭据，再保存映射，最后清除本操作凭据；未知 create 先核查，不因正式映射缺失重复创建。关联 FD 检查所有者和本身两处凭据。
- 附带注意事项已吸收：canonical identity 来自实际记录；旧两参数接口空白归一化与新来源接口的块外精确保留分开；明确远程全 body 更新无 CAS 的竞争窗口。

后续实现评审应检查 pending 登记失败的实际停止路径、部分响应保存失败后的保留行为、独立模式合法性检查，以及旧接口与来源级替换的边界。暂未编写的实现不能以本设计结论代替验证。
