## 实现注意事项

- **D1，低，资源组合安装顺序**：单独拆出的 `aiw-skills-support` 承载根共享资源，而 `aiw-skills.py` 的物化流程会直接读取这些资源。实现 skills 聚合目标时应包含并优先安装 support，再安装各 Skill 包；帮助应说明单独输入某个 Skill ZIP 只安装 canonical 内容，不隐含依赖求解或项目/用户级安装。根插件公共辅助文件包也应保持其原路径，聚合目标覆盖它。现有设计允许这样实现，不需要新接口。
- **D2，低，保留配置的登记寿命**：remove 无备份后仍保留配置，之后 purge 必须仍能按原归属定位这些配置。因此应保留配置登记或等价的已移除记录；不得为了移除 current 而丢弃配置归属。首次安装失败保留下来的配置也应有可诊断的归属记录。无需新命令；由工作项 3.2、3.4.1、3.5 落实。
