- 主要剩余风险是本次插桩范围内 338/548 个分支未命中。38.3% 是 `plugins/aiw-fd.py` 子进程的分支覆盖率，不能代表整个仓库，也不能证明未命中分支正确。它是透明披露的覆盖限制；FD 的验收要求是测量并记录分支覆盖，不是达到指定门槛。
