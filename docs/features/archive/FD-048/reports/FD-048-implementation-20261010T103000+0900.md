## 变更

- 增加 `backend_mode`，旧配置缺省仍为 `codex`；代理模式验证固定 HTTP(S) 上游地址，并从环境变量解析全局或主体级凭据。
- 代理模式在保留网关认证、RPM、主体/全局并发限制的同时，将全部 `/v1` HTTP 路由交给标准库 `ReverseProxy`；本地 `/internal/*` 路由仍由 Gateway 处理。
- 出站请求固定目标主机，替换 Authorization 上游凭据，清除 API Key、组织/项目身份及逐跳转发身份头。HTTP body/SSE 按流转发；支持 WebSocket upgrade，并在关闭时收拢活动连接。
- 代理模式不初始化 Codex App Server、工作目录或持久化 Store；停止命令不依赖代理模式状态锁。
- 更新稳定代理规格、Gateway 文档及独立配置样例。明确代理统计/计费未实现，共享上游凭据意味着共享其权限。
